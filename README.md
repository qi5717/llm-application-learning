# 2026.10.14 PDF RAG系统 v2 - 混合检索（向量+BM25）+ 引用来源

## 项目2：PDF文档问答助手（RAG - 混合检索版）

### 功能
上传PDF文档，基于文档内容智能问答，支持引用来源标注。

### 技术栈
- pypdf：PDF文字提取
- 阿里云百炼 text-embedding-v4：向量化
- DeepSeek：生成回答
- rank_bm25：关键词检索
- numpy：余弦相似度

### 核心流程
1. PDF读取 → 2. 切分（500字+100重叠）→ 3. 向量化
4. 双路检索：向量检索 + BM25检索
5. 合并去重 → 6. 拼接上下文 → 7. 大模型生成 + 引用来源

### 混合检索的价值
- 向量检索：擅长语义相近
- BM25检索：擅长关键词精确匹配
- 两路合并：互补短板，提高召回率
